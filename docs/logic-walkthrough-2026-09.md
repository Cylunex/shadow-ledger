## 关键行为变化

- 月度洞察支持 `timezone`，默认应用配置时区。时间范围按当地月初生成，再转换为 UTC 查询。
  存储/读取 timestamp 使用统一 UTC 类型适配器，保留独立 timezone 字段；PostgreSQL 模式无需变更。
  SQLite 原来已丢失的 offset 无法自动恢复；本次不猜测或改写任何旧日期。
- Money/Quantity 输入接受十进制字符串或整数，不接受 JSON 浮点或 bool；币种为三位 ASCII 字母。
  Record 时间必须携带 offset，时区名称须有效。模型校验不把原始请求时间改写后再计算幂等指纹。
- `/insights/merchants?currency=CNY` 返回 currency，amount 为本币种支出减退款；count 不含退款/收入。
- `/recurring-commitments/{id}/draft` 使用 Idempotency-Key 时，重试仍指向首次解析的 occurrence；
  显式 occurrence 的历史兼容入口保留。暂停/结束不允许新建草稿，但已完成请求可幂等重放。
- Worker 推进 next_due_at 时递增 revision；用户编辑遇到 Worker 更新会产生正常版本冲突。
  草稿仅使提醒标记 handled，不代表付款/确认；界面可从提醒自身日期生成对应草稿。
- 原来仅用 current_actor 的界面控制接口改为用户会话专属，尤其是导出、计划和洞察。
  服务继续使用显式 scope 的记录读取、草稿、采集和集成接口；不要把服务 Token 当用户登录。
- `ledger.write-draft` 不再能通过 PATCH/补金额改写已确认记录；必须具有确认权限。
  Shadow Agent 仍只能经过独立隐藏审批入口改变正式事实，未扩大模型工具能力。
- LAN bypass 默认关闭，除原有头与前缀外还须命中 `lan_bypass_hosts`。前缀解析在 CSRF 前执行且拒绝
  网络路径/控制字符。生产反向代理仍须剥离外部伪造的转发/免登录头，并限制直接访问应用端口；
  主机 allowlist 不是网络来源认证。本次未配置或验证 NAS 网络边界。
