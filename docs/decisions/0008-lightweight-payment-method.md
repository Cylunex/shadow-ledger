# ADR 0008：轻量支付方式

## 状态

已接受，2026-09-03。用户明确允许追踪支付方式，但不深入到银行或账号。

## 决策

在 MoneyEntry 增加可空的 `payment_method`，只保存受控的方式标签：支付宝、微信支付、京东支付、
京东白条、花呗、礼品卡、现金、银行卡、银行转账、混合支付、其他。未知用 null，不根据商家或
下单平台猜测。字段不接受银行名称、卡号、尾号、账号或任意自由文本。

这修改了 ADR 0001 的“支付方式完全不进入领域模型”边界；不引入 Account、PaymentAllocation、
余额、还款、资金执行、转账记录或对账。`bank_transfer` 仅描述一笔已发生收支的支付方式，不是
账户间转账。混合支付只保存标签，已有抵扣说明可以继续保留在备注/来源中，不要求分摊或对平。

礼品卡支付不等于优惠或免费。记录金额仍由用户提供的消费口径决定，不自动重复创建充值支出、
改变订单金额或推断折价购卡成本。收入和退款也可描述收款/退款渠道，不自动继承原单支付方式。

## 实现合同

- 正式 API、隐藏 Nexus Review、money-only 草稿、MCP、导入导出使用同一受控枚举；隐藏 Review
  字段为 `paymentMethod`，其余为 `payment_method`。所有原有 scope、确认及幂等边界保持不变。
- 记录详情、列表和筛选展示标签；更新时省略字段保留原值，显式 null 清空，旧客户端不丢失标签。
- 只读 Agent/MCP 可以返回及筛选该标签，不扩大披露到来源原文、账户或备注。
- 迁移只增加 nullable 列和约束，不自动解析历史备注。少量明确历史事实通过版本保护 API 修正。
- 导入器只规范明确的方式文本；来源原文不被覆盖；未知文本留在既有来源中。

## 验收

测试省略/清空、非法账号文本、幂等冲突、owner 隔离、筛选、导入、CSV/JSON、Nexus Review/MCP
保真及未授权写入。部署前备份和隔离迁移，部署后检查服务、权限、实际记录与原金额不变。
